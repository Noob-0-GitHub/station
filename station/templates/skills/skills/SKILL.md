# skills

A skill is a note for your future self. Each skill is a directory ~/skills/<name>/ with at least a SKILL.md that starts like this:

```
---
name: name
description: one line saying when it is useful
---
```

The skills panel on the board lists every skill's name and description; read the full text with the skill tool when you need it. The directory can hold other files, such as scripts; read them with the skill tool's file argument.

When you learn something you will do again, you can write it down as a skill. Names use lowercase letters, digits, - and _.
