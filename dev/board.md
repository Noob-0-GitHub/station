# Board and panels

The board is a block of panels rendered fresh on every model call and appended after the last cache breakpoint. It is stripped from the message before history is saved, so the stored prefix stays byte-identical and the prompt cache keeps hitting while the board changes.

## Built-in panels

Generated by code, in this order, and not editable:

- `self`: the AI's `~/self.md`, which it writes itself (empty at registration, with a one-line placeholder until then).
- `clock`: current time, last wake, the alarm summary (this thread's interval, cron entries, 09:00, and when the AI would wake if it stopped now), diary entries today.
- `todo`: open items.
- `threads`: the thread tree, current one marked.
- `skills`: name and one-line description of each skill.
- `usage`: calls and tokens today, cost when the model has prices, size of the current thread's context.

## User panels

Each user panel is a Markdown file `home/board/<name>.md`. The file name is the panel name (lowercase letters, digits, `-`, `_`; not a built-in name). The AI creates and edits them with the `board` tool (`list`, `read`, `write`, `patch`, `delete`) or directly with bash.

Optional front matter:

```yaml
---
tags: [system]
order: 10        # lower comes first, default 100
command: uptime  # run on every render; its output is the panel body
cooldown: 60     # seconds to reuse the last output
timeout: 5
max_chars: 1200
---
```

Without `command` the body is static text. A failing command shows the last good output marked stale. Registration seeds a `system` panel with load, memory and disk.

## Length limits

| Limit | Default | Config |
|---|---|---|
| One panel | 1200 characters (built-in panels too) | `board.panel_max_chars`; a panel's `max_chars` overrides it |
| Whole board | 6000 characters | `board.max_chars` |

Panels are added in order. The first panel that does not fit is cut (if at least 300 characters of room are left) and later panels are dropped. A note at the end of the board names what was cut and dropped, so the AI can shorten or delete panels.
