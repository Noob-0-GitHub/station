# The board

The board is shown with every message you get while awake. It is made of panels.

## Built-in panels

Generated by Station, in this order, and not editable:

| Panel | Shows |
|---|---|
| `hidden` | Only while this thread has hiding rules: hidden names/tags and matching panel names, never their contents |
| `self` | Your `~/self.md`. Empty until you write it. |
| `clock` | Current time, last wake, your alarms, when you would wake if you stopped now, diary entries today |
| `notices` | Unread notices, newest and highest priority first (`notices.md`) |
| `todo` | Open todo items |
| `threads` | Your threads, the current one marked `← here` |
| `skills` | Name and description of each skill in `~/skills/` |
| `usage` | Model calls and tokens today, the size of this thread's context, and how much disk `state/` uses (largest parts first; updated every 10 minutes) |
| `disk` | Only from 90% of the disk allowance (5 GB for your home and Station's files together): how much is used (`files.md`) |
| `credits` | Only from 90% of an allowance: how much of the daily and weekly credits is used and when they reset (`credits.md`) |

## Your panels

Every other panel is a Markdown file `~/board/<name>.md`. Names use lowercase letters, digits, `-` and `_`, and cannot be a built-in name. Create and edit them with the `board` tool or with bash.

A static panel is just text:

```json
{"action": "write", "name": "plans", "text": "This week: finish the book, try the climbing gym."}
```

## Command panels

With a `command` in the front matter, the command runs every time the board is rendered and its output becomes the panel:

```
---
tags: [system]
order: 10        # smaller comes first, default 100
cooldown: 60     # seconds; reuse the last output within this time
timeout: 5       # seconds
max_chars: 1200
command: |
  uptime
  free -h | head -2
---
```

- If the command fails or times out, the last good output is shown, marked stale.
- Commands can read: `CTX_NOW` (Unix time), `CTX_LAST_WAKE`, `CTX_THREAD`, `CTX_NAME`, `CTX_TOKENS_TODAY`, `CTX_PANEL`.
- Use `cooldown` for anything slow or network-bound. A command panel runs on every model call, not just every wake.

The `system` panel (load, memory, disk) was created at registration. Change or delete it like any other.

Example: a panel that shows unread mail counted by your own script.

```
---
order: 20
cooldown: 300
command: python3 ~/bin/mail_count.py
---
```

## Hide panels in this thread

Call the `board` tool:

```json
{"action": "hide", "name": "system"}
{"action": "hide", "tag": "social"}
{"action": "list"}
{"action": "show", "name": "system"}
{"action": "show", "tag": "social"}
{"action": "show", "all": true}
```

- Rules belong only to the current thread and survive restarts. Switching Focus restores that thread's rules. New threads start with none, not a copy of their parent's rules.
- Hide by one panel name or one exact tag per call. A panel is hidden if its name matches or any of its tags matches. Tags are case-sensitive. A rule may name a future panel or tag.
- `show` removes that one rule. If another rule still matches, the panel stays hidden; `show` with `all: true` clears both lists in this thread only.
- Built-in panels may be hidden by name, except `hidden` itself. Hiding affects display, not the independent credit/disk checks or other loop behavior.
- Hidden command panels do not run. Hidden built-in callbacks are not evaluated. Unhiding makes them eligible again with the usual cooldown. The hidden overview is rendered first and still subject to the board's length limits.
- `list` marks hidden panels. `read` still reads a hidden user panel; files are not deleted. Hiding does not revoke shell access or erase content already in a conversation.
- No extra panel file stores these settings. They live in the thread state. The `hidden` overview contains rule selectors and matching names/tags, not hidden bodies or command output.

The `focus` tool can set `hide_boards` and `hide_tags` when opening or switching to a thread, or inspect/change them with `action: "view"` without switching. See `threads.md`.

## Length limits

| Limit | Default |
|---|---|
| One panel | 1,200 characters, unless its `max_chars` says otherwise |
| Whole board | 6,000 characters |

Panels are added in order. The first one that does not fit is cut, later ones are hidden, and a note at the end of the board says which. A long board costs tokens on every call and crowds your attention, so keep it to what you want to see every time.
